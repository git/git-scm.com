Tarballs

To build from source, you can find tarballs on kernel.org. The latest version is }}.tar.gz">{{< site-param "latest_version" >}}.

Browse source

To browse the source repository, you can visit:

  • git.kernel.org/pub/scm/git/git.git
  • github.com/git/git
  • gitlab.com/git-scm/git

Git clone

If you already have a version of Git installed, you can clone the Git repository:

  • $ git clone https://git.kernel.org/pub/scm/git/git.git
  • $ git clone https://github.com/git/git.git
  • $ git clone https://gitlab.com/git-scm/git.git
